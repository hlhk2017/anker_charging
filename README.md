# Anker Charging 安克充电 · Home Assistant 集成

对接安克（Anker）充电设备云服务 `aiot-api-cn.anker.com.cn`，把充电器的运行状态、端口功率 / 电量以及可设置的开关接入 Home Assistant。协议通过抓包与逆向 App 独立重实现，不依赖第三方 SDK。

## 主要功能

- **设备实体**：每台充电器自动创建设备，含在线、充电中、今日输出电量、当前总功率、WiFi 信号、固件版本等实体。
- **端口数据**：按端口（C1–C4、A1、A2）提供功率与今日电量传感器。
- **控制功能**：充电模式、端口控制。

## 配置方式

添加集成时提供两种接入方式，二选一即可。

### 方式一：账号密码登录

1. 「设置 → 设备与服务 → 添加集成」，搜索 **安克充电 / Anker Charging**。
2. 选择「账号密码」，填写 **手机号（或邮箱）**、**密码**、**区域**（中国区选 `CN`）。
   - 若账号只开通了验证码登录，请先在安克 App 中设置一次密码。
3. 添加后可在集成「配置」中调整 **刷新间隔**（15–600 秒，默认 60 秒）。

> 安克账号为**单点登录**：在 HA 中使用账号密码登录后，会把手机 App 的登录顶掉；之后在 App 重新登录，HA 里的会话也会失效。

### 方式二：抓包令牌登录（推荐，减少与 App 互踢）

若不想在 HA 里重新登录、或不想把 App 顶下线，可以直接从 App 抓包取得请求头里的 `x-auth-token` 与 `uid` 后配置集成：

1. 用抓包工具（如 Reqable / HttpCanary / Charles / mitmproxy）抓取安克充电 App 的请求。
2. 在任意已登录请求的请求头中找到：
   - **`x-auth-token`**：登录令牌，对应集成里的「令牌」字段（必填）。
   - **`uid`**：用户 ID，对应集成里的「用户 ID」字段（可选，留空时自动推断）。
3. 添加集成时选择「令牌」，粘贴 `x-auth-token`（以及 `uid`），选择区域后提交即可，无需在 HA 中再次登录。

> 这种方式复用的是 App 当前的同一登录会话，因此**只要 App 不再重新登录**，令牌可长期复用；若 App 侧重新登录导致令牌轮换，需重新抓包更新 `x-auth-token`。

## 注意事项

- **单点登录限制**：安克账号同一时间只允许一个有效登录会话。用账号密码在 HA 里配置后会把安克 App 顶下线（App 重新登录也会让 HA 会话失效）。如需长期与 App 共存，建议使用**抓包令牌**方式。
- 数据来自云端轮询（默认 60 秒），不是实时推送；设备自身支持 MQTT，后续可扩展为秒级推送。
- 登录令牌会缓存到 HA 存储，避免频繁登录触发账号登录次数上限。
- 不同机型的设备设置字段可能不同，集成会自动跳过设备未返回的字段。
- 适用于 **Home Assistant 2026.10 及以上**。
- 本项目为非官方集成，与安克官方及 Home Assistant 官方无隶属关系。

## 安装

### 方式一：HACS（推荐）

1. 打开 HACS → **集成** → 右上角菜单 → **自定义仓库**。
2. 添加仓库地址 `https://github.com/hlhk2017/anker_charging`，类别选择 **Integration**。
3. 在 HACS 中搜索并安装，然后**重启 Home Assistant**。
4. 到「设置 → 设备与服务 → 添加集成」搜索对应集成名称进行配置。

### 方式二：手动安装

1. 下载或克隆本仓库。
2. 将 `custom_components/anker_charging` 整个目录复制到 Home Assistant 配置目录的 `custom_components/` 下。
3. 重启 Home Assistant，再在「设置 → 设备与服务 → 添加集成」中添加。
